# SubTrack

Реализация практической работы № 2 по дисциплине «Технологии разработки мобильных приложений».

## Быстрый просмотр

Откройте `prototype/index.html` в браузере и нажмите **Открыть демосценарий**. Установка и сервер не требуются. Демо показывает восемь экранов, позволяет создавать, изменять и архивировать записи. Данные сохраняются в localStorage этого браузера.

Интерактивный макет и Android-приложение — отдельные реализации и отдельные хранилища. В макете используются вымышленные сервисы, текущая дата устройства. Все суммы задаются в российских рублях.

## Android

Готовый установочный файл: `dist/SubTrack-debug.apk`.

Требования: Android 8.0 (API 26) или новее. Начальная база пуста. При первом запуске создайте профиль и добавьте подписки. Приложение не списывает деньги и не подключается к банковским счетам.

Для сборки откройте этот каталог в Android Studio, выберите JDK 17 и установите Android SDK 35. SDK Build Tools 34.0.0 используются совместимой версией AGP. Укажите путь к SDK через `local.properties` или `ANDROID_SDK_ROOT`.

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug assembleRelease lintDebug
```

В Linux/macOS:

```sh
chmod +x gradlew
./gradlew testDebugUnitTest assembleDebug assembleRelease lintDebug
```

Первая сборка загружает Gradle и зависимости из официальных репозиториев.

Стек зафиксирован: Kotlin 2.0.21, AGP 8.7.3, Gradle 8.9, Compose BOM 2024.12.01, Room 2.6.1, Navigation 2.8.5, DataStore 1.1.1. Эти версии выбраны для проверенной совместимости, а не как последние доступные.

## Реализованные функции

- Вход и регистрация локального профиля: имя, почта, пароль и подтверждение.
- Добавление, изменение, поиск, удаление с подтверждением, архивирование и восстановление подписки.
- Только российский рубль (₽); месячный, квартальный, годовой и недельный периоды.
- Пять категорий, признак пробного периода и дни до списания.
- Средняя стоимость за месяц, квартал и год; диаграмма категорий.
- Навигация по восьми экранам и сброс графа при выходе.
- Room для пользователей и подписок; DataStore для темы и сохранения входа.
- Три собственных Compose-компонента: SubscriptionCard, SpendingRing, PeriodSelector.
- Темная тема, состояние загрузки, сообщения об ошибках и пустые состояния.
- Release-сборка с R8 и сокращением ресурсов.

## Расчеты

Сумма хранится целым числом копеек. Расчеты выполняются через BigDecimal, итог отображается с двумя десятичными знаками.

| Период подписки | Средний месячный расход |
| --- | --- |
| Месяц | Стоимость |
| Квартал | Стоимость / 3 |
| Год | Стоимость / 12 |
| Неделя | Стоимость × 52 / 12 |

Это оценка регулярной нагрузки, а не сумма календарных банковских операций. Архив исключен. Все новые и измененные записи сохраняются в рублях.

Контрольный набор: 299 + 499 + 199 + 3024 / 12 = **1249 RUB/месяц**, **14988 RUB/год**.

## Регистрация и хранение

Почта используется как локальный логин: письма не отправляются, облачная учетная запись не создается. Допустимая длина имени — 2–60 символов, пароля — 10–128. Подписки ограничены ownerId как при чтении, так и при изменении.

Пароль хранится как PBKDF2-HMAC-SHA256 (600000 итераций, случайная соль 16 байт, результат 256 бит). Идентификатор вошедшего профиля сохраняется в DataStore; после перезапуска приложения вход восстанавливается. Кнопка «Выйти» удаляет сохранённый сеанс. База не зашифрована, локальный вход не следует считать защитой от владельца root-доступа. Восстановления пароля нет. Резервное копирование и перенос данных отключены в манифесте и правилах Android 12+.

В исходниках нет пользовательских аккаунтов, паролей, банковских данных и API-ключей.

## Рубли и работа без интернета

Поддерживается только российский рубль. В форме нет выбора валюты, в настройках — курсов и кнопки их обновления. Сетевые библиотеки, запросы и разрешение INTERNET удалены. Учет подписок, вход и расчеты работают локально.

При обновлении Android-базы с версии 1 на 2 удаляется только ненужный кеш курсов. Профили и подписки сохраняются. Старая запись с другой валютой не пересчитывается и не включается в итог; откройте ее, нажмите «Редактировать» и укажите стоимость в рублях. Исходная сумма остается в базе до такого сохранения. Прототип обрабатывает старые записи так же.

Сетевая функция из полного задания пока не реализована.

## Макеты и Figma

`design/figma-svg` содержит восемь основных экранов, вариант темной темы и пустого архива. SVG содержит редактируемые фигуры и текст. Импорт: создать файл Figma, перетащить SVG, при необходимости поместить содержимое в фреймы 390 × 844. Переходы собрать по `design/NAVIGATION.md`; SVG не переносит интерактивные связи Figma.

Онлайн-файл Figma в рамках локальной подготовки не создавался. Снимки в отчете получены из интерактивного HTML-прототипа, а не с Android-устройства.

## Release и R8

`dist/SubTrack-release-unsigned.apk` собран с `isMinifyEnabled = true` и `isShrinkResources = true`. `dist/mapping.txt` содержит соответствия исходных и обфусцированных имен. Для установки release необходимо подписать APK собственным ключом; debug-APK уже подписан тестовым ключом среды сборки.

R8 затрудняет анализ, но не делает его невозможным. Ключи публикации в комплект не входят. mapping.txt следует сохранять для диагностики каждой опубликованной версии и не распространять вместе с производственным приложением без необходимости.

## Структура

```text
app/src/main/java/ru/subtrack/
  MainActivity.kt    Главные разделы и навигация
  Forms.kt           Вход, регистрация, поля и календарь
  AccountScreens.kt  Настройки и детали подписки
  ArchiveScreen.kt   Архив и его пустое состояние
  Theme.kt           Цвета, формы и типографика
  AppViewModel.kt    Состояние и обработка действий
  Data.kt           Room, миграция и репозиторий
  Domain.kt         Деньги, даты и пароли
  Components.kt     Собственные UI-компоненты
app/src/test/       Модульные тесты
app/schemas/        Экспорт схемы Room
prototype/          Интерактивный HTML-макет
design/             SVG и карта переходов
docs/               Демонстрация и подтверждения проверок
dist/               APK и mapping.txt
```

В базовой итерации зависимости создаются явно в Application и фабрике ViewModel. Hilt и WorkManager из первоначального плана пока не подключены. Категории заданы списком; отдельная история платежей и фоновые уведомления не реализованы.
