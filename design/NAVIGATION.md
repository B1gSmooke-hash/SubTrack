# Карта экранов SubTrack

Размер каждого SVG: 390 × 844. Основная последовательность импорта — файлы 01–08; 09 демонстрирует темную тему.

| Откуда | Действие | Куда |
| --- | --- | --- |
| Вход | Создать профиль | Регистрация |
| Регистрация | Уже есть профиль | Вход |
| Вход / регистрация | Успешная проверка | Подписки |
| Подписки | Кнопка + | Форма |
| Подписки | Карточка | Детали |
| Детали | Редактировать | Форма с данными |
| Форма | Сохранить | Предыдущий экран |
| Детали | В архив / восстановить | Тот же экран с новым состоянием |
| Детали | Удалить | Подтверждение, затем список |
| Нижняя панель | Подписки / статистика / архив | Соответствующий раздел |
| Основные разделы | Настройки | Настройки |
| Настройки | Выход | Вход с очищенным стеком |

В Figma используйте прототипные связи Navigate to; для формы и деталей — Back на стрелке возврата. Покажите состояния ошибки и пустого списка отдельными вариантами при дальнейшем развитии макета. SVG не хранит интерактивность; работающий локальный сценарий находится в `prototype/index.html`.
