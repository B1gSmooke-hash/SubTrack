# Android 0.3.0

Обновление относится к Kotlin/Compose-приложению. HTML-прототип и SVG-макеты остаются предыдущей версией дизайна.

- Единая светлая и тёмная палитра, новые формы, карточки и основная кнопка добавления.
- Переходы с коротким затуханием и небольшим смещением, отдельная обратная анимация.
- Обводка текстовых полей видна при фокусе. Касание вне поля снимает фокус и скрывает клавиатуру, не блокируя нажатия кнопок.
- Кнопки показа пароля при входе, регистрации и подтверждении пароля. Пароли и состояние показа не сохраняются при пересоздании экрана.
- Календарь для даты списания. Прошедшие даты запрещены как в календаре, так и в проверке перед записью в базу. Старая подписка с прошедшей датой требует выбора новой даты при редактировании.
- Граф навигации авторизованного пользователя не содержит экранов входа. Идентификатор локального профиля сохраняется в DataStore; сеанс завершается по кнопке «Выйти».
- Цветовая легенда диаграммы: название категории, сумма и процент. Нажатие категории раскрывает её подписки; нулевые суммы явно обозначены.

Исходники интерфейса: MainActivity.kt (навигация и экраны), Forms.kt (поля, клавиатура, календарь), Components.kt (карточки, диаграмма, легенда), Theme.kt (палитра и типографика).

Схема Room остаётся версии 2. Обновление поверх версии 0.2.1 сохраняет профили и подписки.
