# Android 0.3.1 — настройки и детали подписки

Реализован выбранный вариант «Крупные карточки»:

- В настройках: зелёная карточка с инициалом, именем и почтой; общий блок темы, валюты и локального хранения; широкая кнопка выхода и версия приложения.
- В деталях: зелёная карточка с иконкой категории, названием и ценой; дата списания в русском формате; отдельные блоки пробного периода и оценки расходов за год.
- Действия: редактирование, архивирование/восстановление и удаление с подтверждением.
- Тёмная тема сохраняет зелёный заголовок с белым текстом; остальные поверхности используют палитру приложения.
- На небольших экранах содержимое прокручивается, чтобы все действия оставались доступны.

Новые компоненты находятся в `AccountScreens.kt`. Данные, расчёты, локальная сессия и схема базы не изменены. Для старых записей с другой валютой по-прежнему требуется указать стоимость в рублях.
