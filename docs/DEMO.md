# Демонстрация SubTrack 0.3.2

## Android

1. Установите SubTrack-debug.apk из релиза v0.3.2. При обновлении устанавливайте поверх предыдущей версии, чтобы сохранить данные.
2. Создайте профиль или войдите. Покажите кнопку видимости пароля. После входа системная кнопка «Назад» не возвращает экран авторизации.
3. Добавьте подписки 299, 499 и 199 ₽ в месяц, а также 3024 ₽ в год. Выбирайте сегодняшнюю или будущую дату в календаре. Итог — 1249 ₽ в месяц.
4. Коснитесь свободной области формы: фокус поля и клавиатура скрываются. Сохраните запись, найдите её через поиск и откройте детали.
5. Покажите зелёную карточку сервиса, дату и оценку за год. Измените сумму, затем верните исходное значение.
6. Откройте статистику. Месяц — 1249 ₽, квартал — 3747 ₽, год — 14988 ₽. Цвета и проценты в списке объясняют диаграмму; категории не нажимаются.
7. Отправьте подписку в архив. Покажите карточку «Сохранённые подписки», откройте детали и восстановите запись. Итог вернётся к исходному.
8. Откройте настройки и включите тёмную тему. Перезапустите приложение: профиль, записи и тема должны сохраниться. Для завершения входа используется кнопка «Выйти».

Записи учебные. Приложение не совершает платежей и не отменяет услуги у поставщиков.

## HTML-прототип

Откройте `prototype/index.html` и нажмите «Открыть демосценарий». Четыре вымышленные подписки уже дают 1249 ₽ в месяц. Даты создаются относительно дня первого открытия демосценария; существующие записи не сдвигаются автоматически. Дальше пройдите действия 4–8. Календарь открывается средствами браузера; внешний вид может отличаться от Android.

Данные прототипа хранятся в localStorage и не синхронизируются с Room в приложении. Кнопка демосценария добавляет учебные записи только один раз. Для чистого примера можно использовать отдельный профиль браузера.

## Подтверждённые проверки

Android проверен в эмуляторе Android 15 API 35. Журналы по версиям находятся в `docs/verification/android-ui-0.3.0.md`, `android-ui-0.3.1.md` и `android-ui-0.3.2.json`. Для 0.3.2 пройдены обновление с сохранением данных, пустой и заполненный архив, открытие деталей, восстановление, неинтерактивная легенда, смена периода и темы. JVM: 12 тестов. HTML-прототип: 23 сценария. Lint: 0 ошибок и 10 предупреждений.

## Проверка перед защитой

- Повторите демонстрацию на том телефоне, который будете показывать. Отдельного протокола проверки физического Android 16 в комплекте нет.
- Проверьте доступность репозитория и скачивание APK с другого устройства.
- При необходимости импортируйте SVG в Figma и настройте переходы по `design/NAVIGATION.md`. Опубликованный онлайн-проект Figma пока не создан.
- Сетевая функция из полного задания остаётся нереализованной. Не представляйте локальное хранение как сетевое взаимодействие.
- Release APK с R8 требует подписи собственным ключом; для текущей демонстрации используйте подписанный debug APK.
