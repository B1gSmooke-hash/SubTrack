# Сценарий демонстрации и приемки

## Быстрая демонстрация макета

1. Открыть `prototype/index.html` → «Открыть демосценарий».
2. Показать четыре активные подписки и 1249 ₽ в месяц.
3. Открыть «Музыка Плюс», изменить сумму и вернуться к списку.
4. Открыть статистику, переключить квартал и год.
5. Переместить запись в архив, показать изменение итога и восстановить ее.
6. Открыть настройки и темную тему; затем показать регистрацию.

Это демонстрация HTML-прототипа; ее данные не передаются Android-приложению.

## Приемка Android — требуется выполнить на устройстве

Все пункты ниже являются планом ручной приемки, а не журналом выполненных проверок.

- [ ] Установить `dist/SubTrack-debug.apk` на API 26+.
- [ ] Создать профиль. Проверить пустое имя, некорректную почту, короткий пароль, несовпадающее подтверждение и повторную почту.
- [ ] Выйти, проверить ошибочный пароль и успешный повторный вход.
- [ ] Добавить месячные подписки 299, 499, 199 RUB и годовую 3024 RUB. Итог: 1249 RUB/месяц, 14988 RUB/год.
- [ ] Отклонить 0, отрицательную сумму, дробную копейку и несуществующую дату.
- [ ] Проверить изменение, поиск, удаление с отменой и подтверждением.
- [ ] Проверить архив и восстановление, пересчет всех вкладок.
- [ ] Проверить категорию, пробный период, ближайшее и просроченное списание.
- [ ] Обновить курсы по сети. Зафиксировать дату, USD и EUR; проверить пересчет Value / Nominal.
- [ ] Отключить сеть, перезапустить процесс, войти и проверить сохранность базы и курсов.
- [ ] Создать второй профиль и проверить изоляцию его подписок.
- [ ] Проверить тему после перезапуска, системную кнопку «Назад», поворот экрана, клавиатуру и прокрутку на маленьком экране.
- [ ] Подписать release собственным ключом и проверить запуск обфусцированной версии отдельно.

Для каждого пункта сохранить версию Android, модель устройства, действие, фактический результат и снимок экрана. Не переносить результаты HTML-проверок в этот список.
