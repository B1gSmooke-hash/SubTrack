# Проверка Android 0.3.0 — 29.10.2026

Среда: Android Emulator, Android 15 (API 35), 1080 × 1920, плотность 420 dpi. Обновление через adb install -r поверх APK 0.2.1 без удаления данных.

## Проверенные сценарии

- После обновления доступен прежний профиль и три сохранённые подписки: сумма 847,00 ₽.
- Вход существующим профилем; показ и скрытие введённого пароля.
- Нажатие «Назад» на главном экране и повторное открытие приложения не возвращают пользователя к входу. Сеанс также восстанавливается после force-stop.
- «Выйти» открывает вход; после force-stop и открытия приложения пользователь остаётся вышедшим.
- Регистрация нового тестового профиля; показ и скрытие подтверждения пароля; возврат назад после регистрации не открывает экран авторизации.
- В календаре 28.10.2026 недоступно, 29.10.2026 доступно. Выбор сегодняшнего дня переносится в форму без смещения даты.
- При открытой клавиатуре касание заголовка снимает фокус с поля (focused=false) и скрывает клавиатуру (mInputShown=false). Нажатия элементов интерфейса продолжают работать.
- Создание тестовой подписки на 199 ₽ увеличивает сумму с 847 до 1046 ₽. Удаление только этой тестовой записи через диалог возвращает 847 ₽.
- В статистике месячная сумма 847 ₽, квартальная 2541 ₽; у категорий отображаются цветовые метки, суммы и проценты (музыка 35,3 %, видео 47,1 %).
- Переключение светлой/тёмной темы и переход обратно на главный экран.

Модульные тесты: 12, без ошибок. Включают запрет прошедших и некорректных дат, сегодняшний/будущий день и преобразование календарных дат в UTC.

Android Lint: 0 ошибок, 10 предупреждений о зависимостях/инструментах сборки. Сборки debug и release с R8 выполнены; debug APK подписан.

Ограничения: это проверка в эмуляторе Android 15. Установка на физический CMF/Nothing с Android 16 и плавность на его оборудовании ещё не подтверждены. Переходы заданы анимациями 140–280 мс; количественный замер частоты кадров не проводился.
